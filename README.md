🧙‍♂️ Wizard Dungeon

Wizard Dungeon is a fast-paced fantasy adventure game where players step into the role of a powerful wizard navigating through dangerous dungeons filled with fire traps, enemies, and magical challenges.

🎮 Gameplay

In this game, you control a wizard who must survive increasingly difficult dungeon levels. Dodge deadly fire traps, avoid hazards, and defeat enemies using magical abilities. Precision, timing, and quick decision-making are key to progressing further.

✨ Features
🔥 Dynamic fire trap mechanics with visual effects
🏰 Immersive dungeon environment with animated elements
🧙 Smooth player movement and responsive controls
⚡ Magic-based gameplay with action-oriented challenges
📱 Mobile-optimized performance and controls
🎯 Increasing difficulty as you advance
🕹️ Controls
Arrow Keys / WASD – Move the wizard
Spacebar / Tap – Use abilities or interact

JavaScript (Canvas-based rendering)
